## Overview

Nibbler is a distraction-free open-source chess analysis interface built specifically for Leela Chess Zero, showing move probabilities (N%), policy scores, and win-rate graphs alongside traditional centipawn evaluation. It also supports Stockfish and any UCI-compatible engine, with a clean layout that keeps the focus on the position rather than the interface chrome.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Nibbler** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Leela Chess Zero Native** | First-class LCZero support with node count and playouts display |
| **UCI Engine Support** | Works with Stockfish, Komodo, and any UCI-compatible chess engine |
| **Move Probabilities** | N% policy probability alongside centipawn evaluation per candidate move |
| **Win-Rate Graph** | Interactive move-by-move win-rate chart across the complete game |
